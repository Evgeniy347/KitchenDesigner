# Встраиваемая техника — общий бриф (Bosch)

Три готовых элемента: варочная поверхность, духовой шкаф, посудомоечная машина.
Модели простые — только параллелепипеды, фиксированные цвета, **размеры не
редактируются** (поля Ш/В/Г в окне свойств задисейблены).

Источник размеров — карточки DNS + монтажные схемы производителя (сняты
16.08.2026, вкладка «Характеристики» + галерея «К описанию товара»).

## Как это ложится на код

### Куда добавлять

| Что | Файл |
|---|---|
| Класс элемента | `Assets/Scripts/Core/Elements/<Name>Element.cs` |
| Пункт каталога | `Assets/Scripts/Core/UI/SidebarCatalog.cs` — новая группа «Техника» |
| Спавн из сайдбара | `Assets/Scripts/Core/UI/SidebarUI.cs:194 Spawn(...)` → `UIManager.Spawn*` |
| Фабрика | `Assets/Scripts/Core/Elements/ElementFactory*.cs` |
| Сериализация | `Persistence/ElementData.cs` (флаг + `FromElement`), `Persistence/SaveLoadManagerInstance.cs` (`RestoreScene`, см. строки 216/342 — ветки `isSink`/`isCooktop`) |
| Окно свойств | `Core/UI/ContextMenuUI.cs` |
| MCP | `Core/MCP/…` — `ParamsCreateElement`, `McpToolRegistry`, `ElementInfo` |

### Эталоны для копирования

- **`CooktopElement.cs`** — врезка в столешницу: два параллелепипеда (плита
  `RIM_HEIGHT_MM` + короб выреза), `IPartCutout`, привязка к детали
  (`AttachedPartName` + `OffsetXMM/OffsetYMM`), магниты, единичный масштаб корня.
- **`SinkElement.cs`** — тот же паттерн с чашей.
- **`AssembledFacadeElement.cs` / `AssembledFacadeMesh.cs`** — сборный фасад со
  стеклянной вставкой (нужен духовке).
- **`DrawerElement.cs` + `DrawerLinks.cs`** — пристёгивание фасада по имени
  (`AttachedFacadeName`), проверка контакта, переименование со связями.

### Блокировка полей Ш/В/Г

Механизм уже есть: `ContextMenuUI.SetDimensionFieldsEditable(bool)`
(`ContextMenuUI.cs:2893`) — гасит `_w/_h/_d` и красит текст в серый. Сейчас
вызывается для ящика. Для техники — общий маркер:

```csharp
/// Элемент фиксированной модели: габариты заданы производителем.
public interface IFixedSizeElement { }
```

`ContextMenuUI.Open()` → `SetDimensionFieldsEditable(!(_target is IFixedSizeElement))`.
Ресайз-ручки тоже надо погасить (`ResizeHandleManager`), иначе размер
правится мышью в обход окна.

### Обязательные правила проекта

- **Единичный масштаб корня**: `localScale = 1` + override `EffectiveScale`,
  иначе дети масштабируются дважды (см. мойку/окно/варочную).
- **WebGL-стриппинг**: примитивы собирать вручную, компоненты добавлять явным
  `AddComponent` — `GameObject.CreatePrimitive` теряет коллайдеры в WebGL-сборке.
- **`[Undoable]` / `[NotUndoable("причина")]`** на КАЖДОМ публичном свойстве —
  иначе `UndoableCoverageTests` роняет сборку.
- **Чек-лист нового свойства** — `AGENTS.md` → «New property checklist» (5 пунктов).
- **Валидация**: роли элементов собираются только в
  `Validation/ValidationSnapshot.cs`; в `Core/Geometry/` нельзя `GetComponent`
  и `is XxxElement` (ловит `GeometryArchitectureTests`).
- **Тесты**: EditMode `.\tools\unity.ps1 tests -Platform EditMode -Filter <Name>Tests`
  (~2 с через шлюз). Полный прогон перед коммитом: `build.cmd -RunTests`.
- Единицы: позиции — метры, размеры — миллиметры.
