## Что меняется

1. Иконки — один набор `IconFactory` 20 px в кнопке 40 (D11); у всех кнопок один фон-состояние.
2. Группы: Файл (новый, открыть, сохранить, сохранить как) | Правка (отменить, вернуть) | Этаж
   (▲ имя ▼, «Этажи…») | Инструменты (замер, линейка, свет) | Режим вида — `Segmented` … справа:
   Панели (Сцена, Ошибки со счётчиком, Спецификация, Инструкции) | Сервис (День/Ночь, Музыка,
   Настройки). Тексты подсказок — прежние ключи.
3. Счётчик ошибок — бейдж 16 `Danger` с белой цифрой 11→13 (`FontCaption`) в правом верхнем углу.
4. Каталог: поле поиска с подсказкой «/», категории — строки 32 с ►/▼ и счётчиком; плитки 2×N на всю
   ширину (2 × 122 + 8); режим дока — тихие иконки `TextSecondary`, не зелёные. Свёрнутая рейка —
   иконки категорий 20 px с tooltip (задача «иконная рейка» из чек-листа уже заявлена).
5. Строка состояния 28 на `NavBg`: значок уровня + текст `Text*`-токеном; справа — постоянные
   индикаторы (автосохранение «2 мин назад», этаж, «Выбрано: N»).
