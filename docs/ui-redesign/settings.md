# Настройки — `SettingsPanelUI`, `Settings*Tab`, `SettingsRowFactory`, `SettingsTabStrip`

Приоритет **2** — окно, которое пользователь назвал первым; 9 разделов, ~90 строк.
Макет: `mockups/settings.png`. Правила: D5, D6, D10, §5, §7. Снимки «до»:
`test-results/settings_tab_*.png`, `script_*_settingspanel.png`.

## Что не так сейчас

| # | Проблема |
|---|---|
| 1 | 900×900 на референсе — на 1366×768 это 640×640 физических при кегле 11 (D1); окно выше канвы при полу масштаба 0,8125 |
| 2 | 8 вкладок разной ширины в одну ленту; в арабском 9-я вкладка вылезает за ширину ленты |
| 3 | Контент — колонка 480 px по центру окна 900: слева 210 px пустоты, справа 210; контролы прижаты к правому краю колонки, на 300 px от своих подписей |
| 4 | Заголовки секций («Участок», «Фундамент») того же кегля и цвета, что подписи строк — не читаются как заголовки; во вкладке «Управление» заголовки уже другие (с линией) |
| 5 | Чекбокс выключен = тёмный квадрат на тёмном, его не видно; включён = синий квадратик 12 px |
| 6 | Ползунок 78 px с бегунком 14×32 и значением в 100 px справа; «Чувствительность 1.0×» с точкой |
| 7 | «Закрыть» внизу дублирует ×; контент вкладок «Свет»/«Фото» уезжает ПОД кнопку «Закрыть» без разделителя |
| 8 | Язык — во вкладке «Проект», хотя это настройка программы; «Качество: Высокое» — кнопка-переключатель без вида списка |
| 9 | «О программе» — текст по центру на 900×900, 60 % пустоты |
| 10 | Заголовок по центру, у остальных окон слева |

## Что меняется

1. 920×640, шапка D5, левая навигация 200 (D6) с поиском и группами; заголовок страницы 20 +
   строка-пояснение.
2. Разделы: Общие (язык, масштаб интерфейса T2, автосохранение) · Проект · Вид · Управление ·
   Свет · Фоторежим · Строительство · MCP · О программе.
3. Колонки 300 | 16 | 240 слева на странице; число 120, список/ползунок 240.
4. Секции — Bold 14 `TextSecondary` с линией, одинаковые на всех страницах (вкладка «Управление» тоже).
5. Булевы — `Switch`; «Качество» — `Segmented` (Низкое / Среднее / Высокое).
6. Ползунок — дорожка на колонку, круглый бегунок 16, значение 64 справа через `NumberFormat`.
7. Футер: «Сбросить раздел» слева (там, где у раздела есть «по умолчанию» — Свет, Фото, Управление),
   без «Закрыть». Свет: кнопка «По умолчанию» с верха страницы переезжает сюда.
8. «О программе»: карточка слева сверху — имя и версия 20, сведения таблицей подпись|значение
   `FontSmall`, кнопка «Скопировать сведения» (для баг-репорта).
9. Привязки клавиш: таблица D8 (шапка 32, строки 34), пустая ячейка — пунктирный контур «—»,
   конфликт — рамка `TextError` + «!» (§10), захват — рамка `FocusRing`.

## Приёмка

- `SettingsNavGuardTests` (замена `SettingsTabStripGuardTests`): каждый раздел достижим из
  навигации, пункт 32 по высоте, `FontBody`, подпись пункта на 10 языках влезает в 200 − 24.
- Поиск: ввод «шаг» оставляет в навигации «Проект», на странице — строку «Шаг сетки»; пустой
  результат — пустое состояние D9.
- `SettingsButtonFitTests`, `HintBadgeVisibilityTests.EveryDeclaredHintKey_GrewABadge_OnTheRealPanel`,
  `LocalizationGuardTests`, `WindowOverflowGuardTests` (на 1366×768 с полом 0,8125) — зелёные.
- Нет кнопки с текстом `common.close` в окне (`NoDuplicateCloseGuardTests`, T3).
- Голдены меняются: `ui_settings_panel_layout`, `ui_settings_tab_*` (10 файлов; переименование в
  `settings_page_*` — тем же коммитом); PNG `script_*_settingspanel` просмотрены глазами (ar — D12).
