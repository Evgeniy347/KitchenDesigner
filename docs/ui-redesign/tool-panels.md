к числу («6000мм»); у каждой строки залитый красный ×; «+» без подписи во всю ширину; текущий этаж
не отмечен; заголовок по центру.

подписью под таблицей. Голдена у окна нет: `ui_floorsettings.verified.json` — сирота без теста-производителя (ни один тест не пишет `floorsettings`), удалить; завести `ui_levels_window` диаграммой.
