## Что меняется

1. Колонки 136 | 12 | 188 (`InspectorLabelW`), все подписи и значения с одного x; отступ 16 — только
   у зависимой подстроки. Контрол 28, шаг 32.
2. Все раскрывающиеся блоки — `CollapsibleSection` (▼/►, Bold 14 `TextSecondary`, счётчик, «+ Добавить»
   справа ссылкой). Пазы, зазоры, кромки, текстуры — секции.
3. Позиция и поворот — подпись строкой («Позиция, мм», «Поворот, °») и три поля на всю ширину с
   префиксом оси в поле; ↻90 — иконная кнопка в конце поля поворота своей оси (tooltip «Повернуть на
   90° вокруг X»). Полоса «X 90° | Y 90° | Z 90°» удаляется.
4. Все числа через `NumberFormat` (T0): «1,0 мм», «26,8 мм».
5. «i» — ребёнок подписи (§13), дорожка `HintBadge.LaneWidth` отнимается у подписи, не у значения.
6. Футер прибит: «Дублировать» слева, «Удалить» справа контуром `DangerText`; заливка `Danger` только
   во взводе `?!`. Тело прокручивается само.
7. «Прозрачный», «Закрепить» — `Switch` в секции «Свойства».
8. Заголовок — «Тип — Имя» (§7) с многоточием, тип — правильный для элемента («Стена — Stena_3000x2500»,
   а не «Деталь — …»). Решение пользователя 2026-10-04: заголовок не меняется, имя по-прежнему и
   в поле «Название».
9. Удаление строки списка — тихий × иконкой 28 (D8), взвод `?!` по §3.
10. Вычисляемые габариты (духовка, ящик) — текст без рамки, подпись погашена (§9), «i» объясняет.

## Приёмка

- По всем типам из `EveryElementType`: левый край каждой подписи строки ∈ {12, 28}, левый край
  каждого значения = 160 (новый сторож `InspectorColumnsGuardTests`, по образцу
  `ContextMenuDisabledRowTests`).
- В панели нет кнопки шире колонки значения, кроме строк секции-списка; нет текста кегля < 13.
- «Удалить» и «Дублировать» видимы без прокрутки у стены с 6 текстурами на 1366×768 (D1).
- Ни одной строки «1.0» / «26.8» в тексте панели на русском (сторож по `NumberFormat`).
- Зелёные: `ContextMenuDisabledRowTests`, `DisabledButtonLabelTests`, `HintBadgeVisibilityTests`,
  `ContextMenuUndoTests`, `PipePanelChoiceUndoGuardTests`, `McpUiPropertyParityTests`,
  `WindowOverflowGuardTests`, `UiNodeOverlapTests`.
- Голдены меняются: все 21 `ui_contextmenu_*.verified.json` — одним коммитом регенерации, PNG
  просмотрены глазами.
