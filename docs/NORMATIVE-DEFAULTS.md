# Нормативные дефолты — сводка для этапов 4–7 (part 3)

Источник задачи: `docs/todo_evolution.md` часть 3 (этапы 1, 4, 6, 7), §3.3 (дефолты),
§3.5 (вентиляция, `VNT-01…03`), §3.6 (правило инженерных констант — число без источника
пункта нормы вносить нельзя, помечать `[Category("NormativeUnverified")]`, если пункт
не удалось открыть и свериться самим).

Confidence: **verified text** — цитата/значение подтверждено нормативным документом или
его официальной публикацией; **typical practice** — цифра из практики проектирования/
статей-калькуляторов, пункт СП не процитирован дословно, требует сверки менеджером перед
внесением как правило (не как дефолт поля).

документа: «дефолты полей, а не инженерные правила»).

Формула ширины подошвы по СП 22.13330 — через расчётное сопротивление грунта
`b = N / (L · R)`, единого табличного «дефолта» ширины СП не даёт — она всегда расчётная.
Для дефолта поля в проекте предлагается взять середину диапазона по толщине стены:
кирпич → 500 мм, лёгкие конструкции → 300 мм — как **typical practice**, не как значение
из текста СП (расходится с §3.6: числа `FND-01`/`FND-02` уже размечены как задача — таблицы
с пунктом СП, которых пока нет).

## 6. Вентиляция — предложение для `VNT-01` и `VNT-03`

Контекст (`docs/todo_evolution.md` §3.5): на слое портов уже определён `VNT-02` —
«твист/профиль не совпадает на стыке» (`PortJoint.Connects` сверяет профиль,
«100×200 не садится на 200×100»). Ниже — обоснование для двух оставшихся кодов, по
аналогии с `FND-01…05` (правило + таблица с источником, §3.6).

| Код | Предлагаемая проверка | Уровень | Источник числа | Confidence |
|---|---|---|---|---|
| `VNT-01` | Скорость воздуха в магистральном воздуховоде превышает рекомендуемую (ориентир: 8 м/с — магистраль, 3–6 м/с — ответвление, 1,5–2,5 м/с — перед решёткой) | Предупреждение | СП 60.13330.2020, приложение Л, табл. Л.1 «Рекомендуемая скорость движения воздуха в воздуховодах систем вентиляции и кондиционирования» (точные числа таблицы Л.1 не процитированы дословно — доступ к тексту не подтверждён) | **NormativeUnverified** — пункт назван, числа из вторичных источников, нужна сверка менеджером по тексту СП 60.13330 приложение Л перед внесением как строгое правило |
| `VNT-03` | Воздухообмен помещения ниже нормативного (кухня 60–90 м³/ч в зависимости от типа плиты, санузел раздельный 25 м³/ч, совмещённый 50 м³/ч; либо кратность ≥ 1 объём/час для помещений с постоянным пребыванием людей) | Ошибка (не набирается сечением/числом решёток заданного типоразмера) | СП 60.13330 (нормы воздухообмена по помещениям) — конкретный пункт не процитирован дословно в собранных источниках | **NormativeUnverified** — то же самое: направление проверки обосновано, пункт СП для итоговой цитаты в тесте нужно сверить по официальному тексту |

Альтернатива для `VNT-01`, ближе к духу уже принятого `PIP-02` (валидация размеров против
настроек): минимальное расстояние между воздуховодом и другими элементами/конструкциями
(отступ для монтажа/изоляции) — в собранных источниках числового норматива не найдено;
скорость воздуха выглядит более сильным кандидатом, так как у неё есть прямая ссылка на
приложение Л и уже есть аналог по духу (`PIP-04` — «подача с подачей», проверка режима
потока).

## Итоговый список того, что не подтверждено текстом и требует `[Category("NormativeUnverified")]`

1. **Ширина/глубина ленты фундамента** — числа typical practice, не из текста СП 22.13330;
   расчёт в СП всегда через R грунта, готовой таблицы «ширина по умолчанию» СП не даёт.
2. **Профлист С20 по ГОСТ 24045** — источники расходятся (1150/1100 либо 1100/1000 мм),
   нужна сверка по тексту ГОСТ.
3. **Толщина минваты для региона «Урал»** — нет готового числа, нужен расчёт по ГСОП
   (СП 131.13330) + СП 50.13330, как уже сделано для `FrostDepthByRegion`.
4. **`VNT-01` — скорость воздуха, приложение Л табл. Л.1** — направление и номер приложения
   подтверждены, точные числа таблицы не процитированы дословно из первоисточника.
5. **`VNT-03` — нормы воздухообмена** — цифры (60–90 / 25 / 50 м³/ч) из вторичных источников
   (сайты вентиляционных компаний), не из текста самого СП 60.13330.
6. **Стандартный ряд прямоугольных воздуховодов по ГОСТ 24751-81** — принцип ряда (R5/R10/
   R20/R40, отношение сторон ≤6,3) подтверждён, полная таблица пар размеров не вычитана.
7. **Высота этажа «не более 2 800/3 000 мм от пола до пола»** — формулировка унаследована от
   СНиП 2.08.01-85; в тексте СП 54.13330.2016 явно найден только норматив по высоте
   помещения (п. 5.7, 2 500/2 700 мм от пола до потолка), не «высоте этажа пол-пол».
