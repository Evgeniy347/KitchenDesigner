# Code conventions & patterns

Карта, а не свод. Правила живут в `conventions/*.md`; читай целиком тот файл, которого
касается задача. Ссылки вида «`CONVENTIONS.md` → «Название раздела»», рассыпанные по коду,
тестам, `AGENTS.md` и старым промптам, ведут в один из файлов ниже — ищи раздел по имени.

| Файл | Что внутри | Читать когда |
|---|---|---|
| `conventions/STRUCTURE.md` | **«Class responsibility (SRP)»**, «A class without a scene lives on the fast path», «Element type checks live in ONE place per layer» | **перед правкой ЛЮБОГО класса** |
| `conventions/COMMENTS.md` | **«Comments live in tests»** — в продакшен-коде комментариев нет | **перед правкой ЛЮБОГО класса** |
| `conventions/SERIALIZATION.md` | снапшот-тесты, «serialize SOURCE OF TRUTH», чтение после `EndCapture`, добавление нового типа элемента и новой настройки, «a decor tiles, it never stretches», имя поля есть часть формата | при любой правке формата, нового типа или настройки |
| `conventions/TEST-NAMING.md` | имена тестов, как доказать, что тест может упасть, недостижимые стражи, взаимоподдерживающие пары, негативные утверждения | **перед тем как писать тест** |
| `conventions/SHAPE-AND-SCREENSHOTS.md` | «A mesh and its metadata must describe the SAME shape» (включая коробку валидации), изометрические скриншот-тесты для новых элементов | при работе с геометрией и мешами |
| `conventions/UNITS-AND-FILES.md` | единицы внутри движка и на проводе MCP, «NEVER delete permanently», общее качество кода | при работе с размерами и при удалении файлов |
| `conventions/CORRECTNESS.md` | `OnDestroy`, шлюз, который умеет только отказывать, атомарность в две фазы, цена удаления теста, порядок сообщений об ошибке, известные долги, «a silent fallback is an outage», «страж спрашивает о той вещи, которую защищает», «чтение `renderer.material` — мутация» | при разборе дефекта и при написании стража |

**Новый раздел попадает в эту таблицу тем же изменением, которое его создаёт.** Файл, переросший
~200 строк, дробится: свод, который перестают дочитывать, хуже карты. `AGENTS.md` и этот файл
разобраны ровно по этой причине.
