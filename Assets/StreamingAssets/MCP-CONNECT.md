# Подключение ИИ-агента к Kitchen Designer (MCP)

Kitchen Designer умеет отдавать сцену наружу по протоколу **MCP** (Model Context
Protocol). Подключив к нему ИИ-агента — Claude Code, Cursor, Codex, любого
другого, — вы сможете просить его расставить короба, выровнять фасады, найти
пересечения и выгрузить спецификацию, а он будет делать это прямо в открытом у
вас проекте.

> **Самый быстрый путь.** Откройте в программе **Настройки → MCP** и нажмите
> «Скопировать инструкцию для агента»: в буфер ляжет короткий текст с адресом
> сервера и вашим настоящим портом. Вставьте его в чат агента — он подключится
> сам. Ниже — то же самое руками.

---

## Как это устроено

```
 агент ──HTTP 127.0.0.1:9337/mcp──▶ Kitchen Designer
```

MCP-сервер живёт **внутри программы**. Пока Kitchen Designer открыт, он слушает
на `http://127.0.0.1:9337/mcp` и говорит по MCP Streamable HTTP. Никаких
посредников, ничего доустанавливать не нужно.

Адрес одинаковый на любой машине, поэтому его можно просто продиктовать агенту.

---

## Что нужно заранее

Только одно: **программа Kitchen Designer запущена**. Закрыли программу —
сервера нет, и агент увидит `connection refused`.

Актуальный порт всегда написан в самой программе: **Настройки → MCP**. По
умолчанию это 9337; его можно изменить, запустив программу с ключом
`-mcpPort 9500`.

---

## Прописать сервер агенту

Имя сервера — `unity-kitchen`. Адрес — `http://127.0.0.1:9337/mcp`.

### Claude Code

```
claude mcp add --transport http unity-kitchen http://127.0.0.1:9337/mcp
```

### Cursor

`.cursor/mcp.json` в проекте (или `~/.cursor/mcp.json` для всех проектов):

```json
{
  "mcpServers": {
    "unity-kitchen": { "url": "http://127.0.0.1:9337/mcp" }
  }
}
```

### VS Code (GitHub Copilot)

`.vscode/mcp.json`:

```json
{
  "servers": {
    "unity-kitchen": { "type": "http", "url": "http://127.0.0.1:9337/mcp" }
  }
}
```

### Codex CLI

`~/.codex/config.toml`:

```toml
[mcp_servers.unity-kitchen]
url = "http://127.0.0.1:9337/mcp"
```

### Claude Desktop

Локальные HTTP-серверы Claude Desktop пока не поддерживает. Отдельный способ
подключения для него появится позже.

### Другой агент

Подойдёт любой клиент, умеющий MCP по HTTP: ему нужен только адрес
`http://127.0.0.1:9337/mcp`. Авторизации нет.

---

## Проверить

Запустите Kitchen Designer и попросите агента вызвать инструмент **`ping`**.
Ответ `{"status":"ok"}` — связь есть, можно работать.

Хорошая первая просьба, чтобы убедиться, что агент видит именно вашу сцену:

> Покажи дерево сцены и скажи, сколько в проекте деталей.

---

## Что агент умеет

- **читать**: `get_scene_tree`, `get_elements`, `get_specification`,
  `get_violations`, `get_free_space`;
- **строить**: `create_elements`, `apply_floorplan` (стены, полы, проёмы одной
  командой), `create_module`;
- **править пачкой**: `edit_elements`, `align_elements`, `distribute_evenly`,
  `clone_elements` — одна отмена на весь пакет, есть `dry_run`;
- **смотреть**: `take_screenshot`, `set_photo_camera`.

Полную шпаргалку агент может прочитать сам — инструмент `guide`.

Две вещи, которые агент обязан помнить (сервер напоминает ему сам, но и вы
знайте): **позиции — в метрах, размеры — в миллиметрах**, и любая правка
возвращает список нарушений сразу, без отдельного запроса.

## Если не подключается

| Симптом | Причина | Что делать |
|---------|---------|-----------|
| `connection refused`, `ECONNREFUSED` | программа не запущена | запустите Kitchen Designer |
| Ответ `403` | запрос пришёл не с этого компьютера или со страницы в браузере | сервер отвечает только своей машине; подключайтесь агентом, а не из браузера |
| В программе написано «Мост остановлен», порт занят | открыт второй экземпляр программы, либо порт занят чужой программой | закройте лишнее окно Kitchen Designer или запустите программу с `-mcpPort 9500` и укажите тот же адрес агенту |
| Агент не видит сервер `unity-kitchen` | конфиг не подхватился | перезапустите агента и проверьте адрес |
| Всё зелёное, но правки не видно | агент подключился к другой копии программы | закройте лишние окна Kitchen Designer, оставьте одно |

Актуальный порт всегда написан в самой программе: **Настройки → MCP**.

---

## Безопасность

Сервер слушает **только localhost** и не требует пароля: любой процесс на вашей
машине, знающий порт, может править открытый проект. Не пробрасывайте порт 9337
наружу и не открывайте его в брандмауэре.

Запросы со страниц в браузере отклоняются: сервер проверяет заголовки `Host` и
`Origin` и отвечает на них `403`.

Агент правит **открытый в программе проект**, а не файл на диске. Сохранение —
за вами; отмена (`Ctrl+Z`) откатывает и то, что сделал агент, причём пакетная
правка откатывается одним шагом.
