# Подключение ИИ-агента к Kitchen Designer (MCP)

Kitchen Designer умеет отдавать сцену наружу по протоколу **MCP** (Model Context
Protocol). Подключив к нему ИИ-агента — Claude Code, Cursor, Codex, любого
другого, — вы сможете просить его расставить короба, выровнять фасады, найти
пересечения и выгрузить спецификацию, а он будет делать это прямо в открытом у
вас проекте.

> **Самый быстрый путь.** Откройте в программе **Настройки → MCP** и нажмите
> «Скопировать инструкцию для агента»: в буфер ляжет эта страница целиком плюс
> строчка с вашим настоящим портом. Вставьте её в чат агента — он всё сделает
> сам. Ниже — то же самое руками.

---

## Как это устроено

```
 агент ──stdio (MCP)──▶ мост mcp-server ──TCP 127.0.0.1:9337──▶ Kitchen Designer
```

Три звена, и каждое может отвалиться отдельно:

1. **Kitchen Designer** — слушает TCP-порт `9337` на localhost. Мост включается
   вместе с программой, отдельно запускать нечего. **Программа должна быть
   ЗАПУЩЕНА**: агент разговаривает с живым приложением, а не с файлом проекта.
2. **`mcp-server`** — маленький Node-процесс из этого репозитория. Он переводит
   вызовы MCP в команды на порт 9337. Агент запускает его сам, вручную стартовать
   не нужно.
3. **Агент** — ему надо один раз прописать, чем и с какими аргументами запускать
   мост.

## Что нужно заранее

| Что | Зачем | Проверка |
|-----|-------|----------|
| Kitchen Designer | собственно сцена | программа запущена, проект открыт |
| [Node.js 20+](https://nodejs.org/) | на нём работает мост | `node --version` |
| [Git](https://git-scm.com/) | забрать мост | `git --version` |

## Шаг 1. Собрать мост

```bash
git clone https://github.com/Evgeniy347/KitchenDesigner.git
cd KitchenDesigner/mcp-server
npm install
npm run build
```

После сборки появится `mcp-server/dist/index.js` — это и есть то, что запускает
агент. **Запомните полный путь к нему**, он понадобится в конфигурации.

Проверить, что мост собран и видит программу:

```bash
node dist/index.js
```

Процесс должен запуститься и ждать (он общается по stdin/stdout, это нормально).
Остановите его — `Ctrl+C`.

## Шаг 2. Прописать сервер агенту

Везде одна и та же тройка: команда `node`, путь к `dist/index.js`, порт в
переменной окружения. Имя сервера — `unity-kitchen`.

Общий вид (JSON):

```json
{
  "mcpServers": {
    "unity-kitchen": {
      "command": "node",
      "args": ["C:/путь/к/KitchenDesigner/mcp-server/dist/index.js"],
      "env": { "UNITY_MCP_PORT": "9337" }
    }
  }
}
```

> Путь пишите **полный**. В Windows либо прямые слэши (`C:/...`), либо двойные
> обратные (`C:\\...`) — одинарный обратный слэш в JSON съедается.

### Claude Code

```bash
claude mcp add unity-kitchen --env UNITY_MCP_PORT=9337 -- node "C:/путь/к/KitchenDesigner/mcp-server/dist/index.js"
```

Либо руками — блок выше в `.mcp.json` в корне проекта (общий для команды) или в
`~/.claude.json` (личный). Проверка: `/mcp` в сессии.

### Claude Desktop

`%APPDATA%\Claude\claude_desktop_config.json` (Windows) или
`~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) —
блок выше целиком. Перезапустите приложение.

### Cursor

`.cursor/mcp.json` в проекте или `~/.cursor/mcp.json` — тот же блок.
Проверка: **Settings → MCP**, сервер должен гореть зелёным.

### VS Code (GitHub Copilot)

`.vscode/mcp.json`, ключ верхнего уровня называется `servers`, а не
`mcpServers`:

```json
{
  "servers": {
    "unity-kitchen": {
      "command": "node",
      "args": ["C:/путь/к/KitchenDesigner/mcp-server/dist/index.js"],
      "env": { "UNITY_MCP_PORT": "9337" }
    }
  }
}
```

### Codex CLI

`~/.codex/config.toml`:

```toml
[mcp_servers.unity-kitchen]
command = "node"
args = ["C:/путь/к/KitchenDesigner/mcp-server/dist/index.js"]
env = { UNITY_MCP_PORT = "9337" }
```

### Другой агент

Если он умеет MCP по stdio — ему хватит трёх вещей: `command: node`,
`args: [<полный путь>/mcp-server/dist/index.js]`, `env: UNITY_MCP_PORT=9337`.

## Шаг 3. Проверить

Запустите Kitchen Designer и попросите агента вызвать инструмент **`ping`**.
Ответ `{"status":"ok"}` — связь есть, можно работать.

Хорошая первая просьба, чтобы убедиться, что агент видит именно вашу сцену:

> Покажи дерево сцены и скажи, сколько в проекте деталей.

## Что агент умеет

Полный список инструментов и правил — в
[`mcp-server/README.md`](../../mcp-server/README.md). Коротко:

- **читать**: `get_scene_tree`, `get_elements`, `get_specification`,
  `get_violations`, `get_free_space`;
- **строить**: `create_elements`, `apply_floorplan` (стены, полы, проёмы одной
  командой), `create_module`;
- **править пачкой**: `edit_elements`, `align_elements`, `distribute_evenly`,
  `clone_elements` — одна отмена на весь пакет, есть `dry_run`;
- **смотреть**: `take_screenshot`, `set_photo_camera`.

Две вещи, которые агент обязан помнить (сервер напоминает ему сам, но и вы
знайте): **позиции — в метрах, размеры — в миллиметрах**, и любая правка
возвращает список нарушений сразу, без отдельного запроса.

## Если не подключается

| Симптом | Причина | Что делать |
|---------|---------|-----------|
| `connection refused`, `ECONNREFUSED` | программа не запущена | запустите Kitchen Designer |
| Агент не видит сервер `unity-kitchen` | конфиг не подхватился | перезапустите агента; проверьте, что путь к `index.js` полный и файл существует |
| `Cannot find module .../dist/index.js` | мост не собран | `npm install && npm run build` в `mcp-server` |
| Порт занят другой программой | конфликт на 9337 | запустите приложение с `-mcpPort 9500` и поставьте тот же номер в `UNITY_MCP_PORT` |
| Всё зелёное, но правки не видно | агент подключился к другой копии программы | закройте лишние окна Kitchen Designer, оставьте одно |

Актуальный порт всегда написан в самой программе: **Настройки → MCP**.

---

## Безопасность

Мост слушает **только localhost** и не требует пароля: любой процесс на вашей
машине, знающий порт, может править открытый проект. Не пробрасывайте порт 9337
наружу и не открывайте его в брандмауэре.

Агент правит **открытый в программе проект**, а не файл на диске. Сохранение —
за вами; отмена (`Ctrl+Z`) откатывает и то, что сделал агент, причём пакетная
правка откатывается одним шагом.
